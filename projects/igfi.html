01 / The overview

What it's about.

IGFI focuses on a single automation use case: Instagram follower growth. Its command-line workflow accepts account and session information, performs the automated process, and reports information about the followers added.

The project README describes support for public and private accounts, a terminal-based interface, and setup instructions for virtual environments and Docker. Reported follower counts in the original documentation are project claims, not guaranteed outcomes.

03 / Behind the work

Under the hood.

Technical approach

IGFI is implemented in Python and documents argument-based execution. The repository also includes environment-specific setup examples and an image-building workflow for Docker.

The README outlines planned features—including a graphical interface and category-specific follower targeting—and identifies previously completed command-line and reporting milestones. Roadmap items are not represented here as existing functionality.

Getting started — abbreviated
git clone https://github.com/new92/igfi
cd igfi
python -m venv .venv
# Activate the environment, then follow the repo README

Consult the repository README for complete setup instructions, requirements, and platform-specific notes.

Worth noting: Automated follower-growth activity may conflict with platform rules or trigger restrictions. Never assume an account is immune from enforcement, and avoid exposing credentials in command-line histories or logs.
